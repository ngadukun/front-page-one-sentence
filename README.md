One sentence that tries to carry an entire newspaper front page in a
single line — the markets, the climate, a birth, a cure, a final
whistle, rain on dry fields, and the editorial hope that holds a
paper together — all in one breath and one full stop.

## The entry

> The world woke poorer, hotter and more divided than yesterday, yet somewhere a child was born, a cure inched closer, a final whistle sparked joy, rain finally fell on dry fields, and humanity, stubborn as ever, chose to begin again.

## Run it

```sh
python3 main.py
```

It prints exactly the sentence above — one sentence, nothing else.
